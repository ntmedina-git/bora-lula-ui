# Cores

As cores entram na interface como tokens com nome e função. **Primitivos** guardam os valores; **papéis semânticos** (no estilo dos color roles do M3) dizem onde usar. Os componentes só usam papéis.

Algumas cores do logo não passam no contraste mínimo com texto branco. **Para texto e botões, use as versões 700.**

## Papéis semânticos

Cada cor de fundo tem um par `on-` para o conteúdo que fica por cima.

## Contraste (WCAG AA)

Calculado a partir dos tokens. Texto normal precisa de **4,5:1**; controles e texto grande (a partir de 24 px, ou 18,5 px em negrito), **3:1**.

<ContrastTable />

> **O amarelo nunca vai como texto, ícone ou borda sobre fundo branco.** Sobre vermelho, só em texto grande (como o "15" de "Faltam 15 dias").
