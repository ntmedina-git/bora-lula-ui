# Espaço e forma

## Espaçamento

Base de 4 px. Padding de cards 16, gutter 24, **48 entre seções no celular e 64 no desktop**.

<SpaceScale />

## Tamanhos

| Token | Valor | Uso |
| --- | --- | --- |
| `--cp-size-touch` | 44 px | **Área de toque mínima** para tudo que é clicável |
| `--cp-size-control-sm` | 36 px | Botão pequeno, **só no desktop** |
| `--cp-size-control-md` | 44 px | Botão e segmento padrão |
| `--cp-size-control-lg` | 52 px | Botão de destaque |
| `--cp-size-icon-sm` / `-md` | 20 / 24 px | Ícones em botões / navegação |

## Raios

Cantos suaves e botões em pílula.
